# Spec Delta

## Purpose

国・地域・共同体と行政区画の候補を、名称や分類から探し、資料の記述と調査状況を確認できるようにする。収録件数と制度の確認状況を分けて示し、訪問先の採否を検討するための情報を提供する。

## ADDED Requirements

### Requirement: 地域台帳の閲覧

システムは、記録・プレビューから移動できる「地域を探す」画面を提供し、配信された台帳のすべての地域を一覧で閲覧できるようにしなければならない（SHALL）。日本語名、原名、分類、既存の選択肢か追加候補か、資料の確認状況を表示しなければならない（SHALL）。

#### Scenario: 台帳の一覧を開く
- **WHEN** ユーザーが「地域を探す」を開く
- **THEN** 地域台帳が表示され、絞り込み前の収録件数を確認できる
- **AND** 既存の選択肢と追加を検討する候補を区別できる

#### Scenario: 閲覧後に記録へ戻る
- **WHEN** 訪問記録がある状態で地域台帳を閲覧してから記録画面へ戻る
- **THEN** 元の訪問記録が維持され、台帳で閲覧した地域の記録は自動追加されない

### Requirement: 名称とコードの検索

システムは、日本語名・原名・別名・国コード・対応する行政区画コードで部分一致検索できなければならない（SHALL）。ひらがなとカタカナ、英字の大小、全角と半角を検索時に同じものとして扱い、前方一致を優先しなければならない（SHALL）。空の検索では絞り込まず、一致しない場合は結果がないことを示さなければならない（SHALL）。

#### Scenario: 地域の別名を検索する
- **WHEN** 「ががうじあ」「Gagauzia」「ｍｄ－ｇａ」のいずれかを検索する
- **THEN** ガガウズが結果に含まれる

#### Scenario: 一般的な国名を検索する
- **WHEN** 「中国」または「韓国」を検索する
- **THEN** 対応する既存の国の候補が結果に含まれる

#### Scenario: 該当する候補がない
- **WHEN** 台帳に一致しない文字列を検索する
- **THEN** 結果0件であることと、条件を解除する操作が表示される

### Requirement: 条件を組み合わせた絞り込み

システムは、関連する国・地域、分類、資料の確認状況、既存の選択肢か追加候補かによる絞り込みを提供し、検索文字列と同時に適用できなければならない（SHALL）。分類は複数の属性を持つ地域を取りこぼさず、候補・主張・歴史上の地位を確定済みの現在の地位と区別しなければならない（SHALL）。関連先の選択を領有権の認定として表示してはならない（MUST NOT）。

#### Scenario: モルドバに関連する候補を探す
- **WHEN** 関連する国・地域をモルドバ、掲載区分を追加候補にする
- **THEN** ガガウズと沿ドニエストルが表示される

#### Scenario: 自治の候補を探す
- **WHEN** 分類を自治制度にする
- **THEN** 特別自治・自治州・自治県など、対応する属性を持つ地域が表示される
- **AND** 資料未確認の候補は、確認済みの制度として表示されない

### Requirement: 行政区画の参照一覧

システムは、地域台帳とは別に行政区画の参照一覧を閲覧・検索でき、原名・コード・上位コード・関連する国を確認できなければならない（SHALL）。重点台帳との対応がある行から、その地域の詳細へ移動できなければならない（SHALL）。参照一覧への掲載を、高度自治の認定や現在の制度確認の完了として表示してはならない（MUST NOT）。

#### Scenario: インドネシアの行政区画を探す
- **WHEN** 行政区画の参照一覧に切り替え、国をインドネシアにする
- **THEN** 参照版に収録された同国の行だけが表示される
- **AND** 各行の原名・コード・上位コードを確認できる

#### Scenario: 古い参照名称を確認する
- **WHEN** PH-14の詳細を見る
- **THEN** 参照版の旧ARMMの名称と、現在のバンサモロとの対応が未確認である注意が表示される
- **AND** 名称や対応する地域が自動で上書きされない

### Requirement: 資料と未確認事項の詳細

システムは、地域の詳細に、出典付きの記述、資料の対象時点と確認日、未確認事項、出典の立場と制約を表示しなければならない（SHALL）。記述未確認、値未入力、採否保留を、それぞれ明示しなければならない（SHALL）。未入力の電話国番号・ドメイン・自治権限を「なし」と表示してはならない（MUST NOT）。

#### Scenario: 地域の根拠を読む
- **WHEN** スルプスカ共和国の詳細を開く
- **THEN** 分類の根拠となる記述、出典へのリンク、資料の制約と未確認事項を確認できる

#### Scenario: 現在の確認を残す資料を読む
- **WHEN** 現行制度との照合が必要な記述を含む地域を開く
- **THEN** その記述を現在の確認が必要なものとして表示し、出典の対象時点と確認日を混同しない

#### Scenario: 補助属性が未入力である
- **WHEN** 電話国番号またはドメインが未入力の地域を開く
- **THEN** 未確認または未入力と表示され、存在しないとは表示されない

### Requirement: 調査の進捗と照合範囲

システムは、国・地域別の調査状況と、出典の一覧との収録照合を確認できるようにしなければならない（SHALL）。未確認・一部確認・調査完了の件数を台帳から求め、各照合集合の範囲・件数・残る制約を示さなければならない（SHALL）。収録件数の一致を、国全体や世界全体の制度調査の完了と表示してはならない（MUST NOT）。

#### Scenario: 世界全体の調査状況を見る
- **WHEN** ユーザーが調査状況を見る
- **THEN** 台帳の未確認・一部確認・調査完了の件数が表示される
- **AND** 行政区画の取り込み件数と調査完了件数が区別される

#### Scenario: スペインの収録照合を見る
- **WHEN** スペインに関連する候補と照合状況を見る
- **THEN** 自治州17件と自治都市2件の各照合範囲、対応する候補、残る権限確認を確認できる

### Requirement: 多数の候補と画面幅への対応

システムは、多数の検索結果をページに分け、すべての結果へ移動できるようにしなければならない（SHALL）。条件を変更したら結果の先頭を表示しなければならない（SHALL）。PCとスマートフォンで検索・条件変更・詳細の開閉を利用でき、キーボードで操作できなければならない（SHALL）。

#### Scenario: 絞り込み後に結果が別ページへ取り残されない
- **WHEN** 結果の2ページ目以後で検索条件を変更する
- **THEN** 新しい結果の先頭ページが表示される

#### Scenario: 詳細を閉じて一覧へ戻る
- **WHEN** 一覧から詳細を開いて閉じる
- **THEN** 元の検索条件とページ位置が保持される

### Requirement: 同梱データと利用条件

システムは、検索・分類・調査状況の閲覧に必要なデータと許諾表示を同梱し、外部APIを必要としてはならない（MUST NOT）。出典の外部ページはユーザーがリンクを開いたときだけアクセスしなければならない（SHALL）。台帳の利用によって、訪問記録の内容を外部へ送信してはならない（MUST NOT）。

#### Scenario: 外部APIが使えない
- **WHEN** アプリの配信元以外への通信を遮断して地域を検索する
- **THEN** 台帳・行政区画・調査状況の閲覧が使える
- **AND** 出典のページへはリンクを開く操作によって移動する

#### Scenario: データの利用条件を見る
- **WHEN** 利用者が同梱データのライセンスを開く
- **THEN** 参照データの提供元、固定版、許諾文を確認できる
