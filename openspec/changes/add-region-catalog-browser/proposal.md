# Proposal

## Why

地域台帳には既存250候補と追加66候補、行政区画の参照行5,070件があるが、アプリでは検索・比較できない。地域を漏れなく探すための第一段階として、台帳を読み込み、分類・出典・未確認事項を確認できる画面を作る。

## What Changes

- 記録・プレビューに加えて「地域を探す」画面を設ける。
- 地域台帳と行政区画の参照一覧を切り替え、日本語名・原名・別名・コードで検索できるようにする。国・地域、分類、確認状況による絞り込みを組み合わせる。
- 各地域の詳細で、資料に記載された内容、対象時点、出典、未確認事項、関連する行政区画を確認できるようにする。
- 既存の選択肢、追加を検討する候補、行政区画の参照行を区別する。分類名や行政区画の掲載だけから、高度自治・国家性・訪問先への採用を認定しない。
- 国・地域別の調査状況と、出典の一覧との収録照合を表示し、収録済み件数と調査完了件数を区別する。
- PCとスマートフォンで既存の配色・ナビゲーション・詳細シートを使う。表示データと利用条件を同梱し、外部APIを使わずに検索できるようにする。
- 今回は調査・閲覧の仕組みを対象とする。訪問記録への地域追加、保存形式の移行、境界データの追加、地図・動画の描画拡張、台帳を画面から編集する機能は、別の変更として扱う。

## Capabilities

### New Capabilities

- `region-catalog`: 国・地域・共同体および行政区画の候補を検索し、分類、資料の記述、出典、調査状況を確認する。

### Modified Capabilities

（なし。既存の訪問記録・地図・動画の仕様は変更しない。）

## Impact

- `apps/web/src/App.tsx`の画面切り替えと、`apps/web/src/catalog/`に新設するデータ層・閲覧画面を対象とする。
- `docs/region-catalog/`のJSONを原本として使う。アプリ用に別の地域一覧を手作業で複製しない。
- `apps/web/src/index.css`、必要なデータのライセンス表示、`docs/design-guidelines.md`、`docs/region-catalog/README.md`、ルート`README.md`を更新する。
- 検索・絞り込みと原本の整合性をテストする。ライブラリ追加、サーバー、認証、データベース、外部への記録送信は不要。
- 既存の`add-selectable-disputed-regions`は訪問記録・地図の拡張案として保持し、本変更とは分ける。同案の地域採用や集計仕様を、この閲覧画面の追加によって確定しない。
