# Spec Delta

## ADDED Requirements

### Requirement: 北方四島の日本向け表示
システムは、日本向けの地図表示として北方四島（択捉島、国後島、色丹島、歯舞群島）の形状を日本の描画範囲として扱わなければならない（SHALL）。ロシアだけの訪問で四島を塗ってはならず（MUST NOT）、日本の訪問で四島を塗らなければならない（SHALL）。記録画面、プレビュー、動画の通常表示と強調表示に同じ方針を適用しなければならない（SHALL）。

#### Scenario: ロシアだけを記録する
- **WHEN** ロシアが訪問済みで日本が未訪問である
- **THEN** ロシアの描画範囲が塗られ、北方四島は未訪問の色で表示される

#### Scenario: 日本だけを記録する
- **WHEN** 日本が訪問済みでロシアが未訪問である
- **THEN** 北方四島が日本のほかの島とともに塗られ、得撫島とサハリンは未訪問の色で表示される

#### Scenario: 訪問状態の組み合わせを表示する
- **WHEN** 日本とロシアの両方が訪問済み、または両方が未訪問である
- **THEN** 北方四島はそれぞれ訪問済みの色、または未訪問の色で表示される

#### Scenario: ロシアの初訪問を強調する
- **WHEN** プレビューまたは動画でロシアの初訪問が強調される
- **THEN** 北方四島にロシアの強調色や光彩を描かない

#### Scenario: 近隣の島を維持する
- **WHEN** 北方四島の描画範囲を適用する
- **THEN** 得撫島とサハリンはロシア、北海道は日本に属する描画範囲として維持され、形状の欠落や二重の割り当ては発生しない
