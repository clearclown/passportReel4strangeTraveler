# Proposal

## Why

現在の検索候補は `i18n-iso-countries` の日本語データに限られ、地図との照合も ISO 数値コードに依存しているため、コソボは選べても地図に反映されず、北キプロスやソマリランドは選べない。自治地域や自由都市・ミクロネーションへの訪問も記録したいという要望に合わせ、ISO にない訪問先を追加できる仕組みへ広げる。

## What Changes

- 既存250件の国・地域を維持し、地域台帳の追加候補のうち歴史上の統治体を除く65件を訪問先として追加する。沿ドニエストル、北キプロス、ソマリランド、自治地域、先住民領域、共同体を含む。コソボは既存の `XK` の記録を地図形状に対応させる。
- オーランド諸島（AX）、グリーンランド（GL）、フェロー諸島（FO）は既に候補と地図形状があるため、親国とは独立して記録・表示できることを回帰確認する。
- ISO にない地域は安定した `region:<識別名>` で識別する。保存形式を v2 にし、既存 v1 の記録とコードを保持して読み込む。
- 基本の地図は現在の `world-atlas` 50m を維持する。スルプスカ共和国は追加の境界形状、既存の面形状がない追加地域は出典付きの代表地点のマーカーで、記録画面・プレビュー・動画に反映する。
- 入力欄と集計を「国・地域」の表記にそろえ、ISO コードを持たない訪問先にも日本語名と種別を示す。地域の追加によって親国の記録を自動追加しない。
- 今回の実装対象は、台帳の現存候補65件と既存候補の維持とする。台帳の詳細から訪問記録の入力へ移動できるようにする。クライナ・セルビア人共和国などの歴史上の国家は、当時の訪問と現在の史跡訪問のどちらを記録するか、年ごとの境界をどう扱うかを別途決める。世界の全自治地域・全ミクロネーションの網羅、Leaflet への描画方式の移行も本変更には含めない。

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `visit-records`: ISO にない地域の検索・識別・一覧・保存と、国・地域としての集計を定める。
- `world-map`: 既存の未対応形状との照合、追加の自治地域の形状、自由都市の地点マーカーと、親国との表示関係を定める。
- `region-catalog`: 台帳の詳細から、選べる地域の訪問記録入力へ移動する。
- `timeline-animation`: 追加地域の初訪問・再訪・累計と、日本語名・地図・マーカーをプレビューと動画に反映する。

## Impact

- `apps/web/src/` に台帳原本から生成する訪問先データを追加し、`records/countryNames.ts` と `map/countries.ts` から共通利用する。
- `records/storage.ts`、`visitRecords.ts` と関連テスト、入力・一覧・集計の UI を更新する。
- `map/drawWorldMap.ts` と関連テストを更新し、追加境界の同梱データと出典・利用条件を文書化する。
- `timeline/` の日本語名・数の表記と関連テスト、`docs/design-guidelines.md`、`README.md` を更新する。動画のエンコーダー・形式・共有処理と、既存依存ライブラリの版数は維持する。
