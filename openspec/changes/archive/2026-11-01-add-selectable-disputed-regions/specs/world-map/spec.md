# Spec Delta

## MODIFIED Requirements

### Requirement: 訪問国のハイライト
システムは、訪問済みの国・地域の集合（既存の国コードまたは地域識別子）を受け取り、該当する国を未訪問の国と区別できる色で塗らなければならない（SHALL）。国境データで親国の形状に含まれる海外領土（フランスの GF・GP・MQ・YT・RE、ノルウェーの SJ、オランダの BQ）は、親国とは別の国として扱い、親国を登録しても塗ってはならず（MUST NOT）、海外領土のコードを登録したときにその地域を塗らなければならない（SHALL）。

#### Scenario: 訪問国が塗り分けられる
- **WHEN** 訪問済みの国の集合に `JP` と `FR` が含まれる
- **THEN** 日本とフランスがハイライト色で塗られ、それ以外の国は未訪問の色で塗られる

#### Scenario: 訪問国がない
- **WHEN** 訪問済みの国の集合が空である
- **THEN** すべての国が未訪問の色で塗られる

#### Scenario: 親国を登録しても海外領土は塗られない
- **WHEN** 訪問済みの国の集合に `FR` が含まれ、`GF` が含まれない
- **THEN** フランス本土とコルシカが塗られ、フランス領ギアナは未訪問の色で塗られる

#### Scenario: 海外領土を登録するとその地域が塗られる
- **WHEN** 訪問済みの国の集合に `GF` が含まれ、`FR` が含まれない
- **THEN** フランス領ギアナが塗られ、フランス本土は未訪問の色で塗られる

#### Scenario: 小さな海外領土にマーカーが出る
- **WHEN** 訪問済みの国の集合に `GP`（グアドループ）が含まれる
- **THEN** グアドループの位置にマーカーが表示される

#### Scenario: ISO 数値コードがない地域を塗る
- **WHEN** コソボ、北キプロス、ソマリランドのいずれかだけが訪問済みである
- **THEN** その地域の既存の形状だけが塗られ、隣接するセルビア、キプロス、ソマリアの形状は未訪問の色のままである

#### Scenario: 既存の自治地域を親国と別に塗る
- **WHEN** AX、GL、FO が訪問済みで、FI と DK が未訪問である
- **THEN** オーランド諸島、グリーンランド、フェロー諸島が塗られ、フィンランド本土とデンマーク本土は未訪問の色のままである

#### Scenario: 親国だけを記録する
- **WHEN** FI と DK が訪問済みで、AX、GL、FO は未訪問である
- **THEN** 既存データで分離されているオーランド諸島、グリーンランド、フェロー諸島の形状は未訪問の色のままである

## ADDED Requirements

### Requirement: 追加地域の代表地点
システムは、訪問済みの追加地域に対応する面形状がない場合、出典を確認した代表地点をマーカーで表示しなければならない（SHALL）。代表地点を地域全体の境界や統治範囲として示してはならず（MUST NOT）、未訪問の追加地域のマーカーを表示してはならない（MUST NOT）。記録画面と動画は同じ地点・形状を使わなければならない（SHALL）。

#### Scenario: 沿ドニエストルだけを訪問する
- **WHEN** 沿ドニエストルだけが訪問済みである
- **THEN** 同地域の代表地点にマーカーが出て、モルドバ全体は未訪問の色のままである

#### Scenario: 全追加地域を描画できる
- **WHEN** 選択可能な追加地域を訪問記録に含める
- **THEN** その地域は対応する面形状または代表地点で表示され、地点表示のために実行時の外部APIを必要としない

### Requirement: 国の内部にある自治地域の表示
システムは、スルプスカ共和国の訪問を、その地域の境界形状で表示しなければならない（SHALL）。その地域だけを登録してもボスニア・ヘルツェゴビナ全域を塗ってはならない（MUST NOT）。ボスニア・ヘルツェゴビナを登録した場合は従来どおり国全体を塗り、自治地域の未訪問表示によって国の塗りを消してはならない（MUST NOT）。

#### Scenario: 自治地域だけを登録する
- **WHEN** スルプスカ共和国だけが訪問済みである
- **THEN** 同地域の形状が塗られ、ボスニア・ヘルツェゴビナのほかの範囲は未訪問の色のままである

#### Scenario: 国全体の塗りを維持する
- **WHEN** ボスニア・ヘルツェゴビナだけが訪問済みである
- **THEN** 同国全体が塗られ、スルプスカ共和国の未訪問状態によって穴や未訪問色の領域は作られない

### Requirement: 自由都市とミクロネーションの地点表示
システムは、クリスチャニア自由都市とウジュピス共和国の訪問を、それぞれ確認された代表地点のマーカーで表示しなければならない（SHALL）。未訪問の地域にマーカーを表示してはならず（MUST NOT）、地域だけを登録してデンマークやリトアニア全体を塗ってはならない（MUST NOT）。追加の境界データと位置はアプリに同梱し、表示時に外部 API を必要としてはならない（MUST NOT）。

#### Scenario: 自由都市の位置にマーカーを表示する
- **WHEN** クリスチャニア自由都市とウジュピス共和国だけが訪問済みである
- **THEN** コペンハーゲンとヴィリニュスの各代表地点にマーカーが表示され、デンマークとリトアニアは未訪問の色のままである

#### Scenario: 親国を登録しても自由都市のマーカーを追加しない
- **WHEN** デンマークとリトアニアだけが訪問済みである
- **THEN** クリスチャニア自由都市とウジュピス共和国の訪問マーカーは表示されない

#### Scenario: 地点の記録を削除する
- **WHEN** クリスチャニア自由都市の最後の記録を削除する
- **THEN** 同地域のマーカーが消え、ほかの訪問先の表示は維持される

#### Scenario: 外部通信が使えない
- **WHEN** アプリの配信元以外への通信を遮断し、追加地域の記録がある状態でアプリを開く
- **THEN** 追加地域の形状と訪問マーカーが表示される
