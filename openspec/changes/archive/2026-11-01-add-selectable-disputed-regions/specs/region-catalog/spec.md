# Spec Delta

## Purpose

国・地域・共同体と行政区画の候補を、名称や分類から探し、資料の記述と調査状況を確認できるようにする。収録件数と制度の確認状況を分けて示し、訪問先の採否を検討するための情報を提供する。

## ADDED Requirements

### Requirement: 地域の詳細から記録する
システムは、訪問先として採用された地域の詳細に、年と地域を選んで記録を追加する画面への操作を提供しなければならない（SHALL）。移動先では地域が選択済みになり、ユーザーが追加を実行するまでは記録を変更してはならない（MUST NOT）。

#### Scenario: 台帳から沿ドニエストルを記録する
- **WHEN** 沿ドニエストルの詳細で訪問記録への追加を選ぶ
- **THEN** 記録画面が開き、沿ドニエストルが選択済みで年を選べる
- **AND** 追加を実行すると訪問記録と地図に反映される
