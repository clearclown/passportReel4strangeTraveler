# Design

## Context

訪問先の検索は日本語の国名データ、保存形式v1は2文字コードに限定されている。地図はworld-atlasのISO数値コードで照合するため、コソボなどの無番号の形状や追加地域を反映できない。地域台帳と閲覧画面は作成済みである。ユーザーは沿ドニエストルを含む追加地域を、閲覧だけでなく訪問記録に使うことを指定した。

## Goals / Non-Goals

**Goals:**

- 台帳原本から訪問先データを生成し、現存候補65件を検索・保存・地図・プレビュー・動画に共通して使う。
- 既存250件とv1データを保持し、親国と地域の訪問を別々に扱う。
- ローカルのビルド済みアプリで利用できる。表示のための外部APIを加えない。

**Non-Goals:**

- 歴史上の統治体の訪問時点・境界は今回決めない。行政区画の参照5,070件を自動採用しない。
- 分類資料が未確認の地域を高度自治や国家として認定しない。

## Decisions

### 台帳から小さな訪問先データを生成する

地域台帳を原本とし、追加の代表地点を出典・版付きのJSONに保管する。生成スクリプトが選べる地域の名称・別名・種別・代表地点を小さなJSONへ出力する。生成結果をチェックするコマンドも用意し、原本とアプリの不一致を検出する。記録画面で検索するために大きな行政区画一覧を読み込む方法は採らない。

追加地域の`applicationCode`には台帳の安定したIDを設定し、任意の訪問先としての採用理由を記録する。制度の確認状況は変更しない。歴史上の統治体の採否は保留する。

### 保存形式v2で地域IDも扱う

既存の`country`フィールドと保存キーは維持する。v1は従来の2文字コードとして、v2は2文字コードまたは`region:<slug>`として読み、保存時にv2へ更新する。未知の地域IDでも形式が正しければ保持し、台帳更新だけで既存記録を消さない。記録の同一性・再訪・集計は年と訪問先IDで決まる。

### 面形状と代表地点を同じ描画経路に載せる

world-atlasの固定版の名前からKosovo、N. Cyprus、Somalilandを明示的に照合する。スルプスカ共和国はgeoBoundariesの固定コミットの境界を追加のオーバーレイにする。未訪問のオーバーレイを描いて親国の訪問色を消さない。

ほかの地域はWikidataの版を固定した代表座標を使う。座標は地域の概略位置または地域内の集落で、境界・実効支配を表さない。追加地域はPointの地物として描画計画へ渡し、訪問済みの地点だけをマーカーで描く。既存の面形状がある地域には重複するPointを追加しない。記録・プレビュー・動画は同じ地図関数を使う。

### 台帳から記録画面へつなぐ

詳細に「訪問記録に追加」の操作を設け、Appが地域IDを記録画面に渡す。地域を選択済みにし、スマートフォンでは入力シートを開く。追加操作を実行するまで記録は変えない。内部IDを利用者に見せず、日本語名と地域の種別を候補・一覧に出す。

集計の表記を「か国・地域」に統一する。親国を自動追加せず、同じ地域の複数年の記録を1件と数える。名前の長さが増えるため、動画の国数の行と残り件数の表示も確認する。

## Risks / Trade-offs

- 代表地点では地域の範囲が分からない → 地点表示であることを画面と台帳に示す。
- 境界の対象年が古い → geoBoundariesの2013年対象の形状として出典・版・利用条件を同梱する。
- 自治制度の参照データに誤ったコード対応がある → コードだけで境界を自動採用せず、今回確認した形状だけを使う。
- 未承認地域と親国の集計が重なる → 集計は訪問先IDの件数であると表記し、親国を推定して追加しない。

## Migration Plan

生成データ、v1/v2互換読み込み、UI、描画を追加し、回帰テストと本番ビルドを実行する。ローカルのプレビューを更新して配信する。保存はユーザーの追加・削除操作時にのみ更新し、読み込みだけでv1を上書きしない。
